# Components Directory

Este directorio almacenará fragmentos de HTML (`.html`) reutilizables o plantillas. 
Por ejemplo:
- `navbar.html`
- `modals/checkout-modal.html`
- `modals/client-modal.html`

Estos serán cargados dinámicamente mediante `fetch()` en la lógica de JS para mantener el `index.html` limpio y el proyecto modular.
